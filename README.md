# HERO Labs website

Static GitHub Pages site for **HERO Labs — Human Enhancement Research in Open Source Software**.

## Publish on GitHub Pages

1. Create a repository such as `hero-labs.github.io` (or use your preferred GitHub Pages repository).
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will publish the site automatically.

## Main files

- `index.html` — homepage
- `research.html` — research themes and project directions
- `people.html` — lab members
- `publications.html` — selected publications
- `join.html` — recruitment/collaboration page
- `styles.css` — all visual styling
- `script.js` — mobile menu and reveal animations
- `assets/` — official HERO Labs logo files and custom vector graphics

## Customization

Search the HTML files for names, publication entries, emails, and text you want to update. The site intentionally avoids a large anime-character hero; instead it uses subtle youthful cues (handwritten notes, motion, colorful research mapping) while keeping the overall presentation professional and minimal.

The current external paper link uses the public arXiv page for `2608.24720`. Replace/add links as desired.
